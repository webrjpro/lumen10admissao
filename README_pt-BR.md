# Lumen10 Inscrições e Admissão

Versão **1.3.0 / 2026110900**, para Moodle **5.1 e 5.2**.

Instale/envie somente [mod_lumen10admissao-1.3.0.zip](dist/mod_lumen10admissao-1.3.0.zip). Não existe plugin auxiliar obrigatório. O Prontuário é uma integração opcional instalada separadamente; sem ele, o aluno utiliza o curso nativo da Secretaria.

Consulte a [documentação completa em português](mod_lumen10admissao/README_pt-BR.md), a [documentação em inglês](mod_lumen10admissao/README.md), os [testes](VALIDATION.md), as [alterações](CHANGELOG.md) e o [suporte público](https://github.com/webrjpro/lumen10admissao/issues). O ZIP geral de código-fonte do GitHub não deve ser enviado como plugin único.

Os testes e a publicação não significam aprovação do Marketplace. Faça backup antes de atualizar e configure SMTP/cron, capacidades, período, privacidade e retenção de acordo com a instituição. O padrão 0 desativa a exclusão automática de pedidos sem aprovação. Guardian IA e outros produtos Lumen10 não integram este pacote.
